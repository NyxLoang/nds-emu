# 十六进制与小端（零基础）

## 为什么是十六进制

电脑内部只认 0 和 1（二进制），但一长串 `10110010001101010111010000111000` 很难看，也容易抄错。

十六进制用 `0`~`9` 和 `A`~`F` 表示 0~15，**每 4 位二进制恰好对应 1 位十六进制**：

| 二进制 | 十六进制 | 十进制 |
|--------|---------|--------|
| `0000` | `0` | 0 |
| `0001` | `1` | 1 |
| `0111` | `7` | 7 |
| `1010` | `A` | 10 |
| `1111` | `F` | 15 |
| `1001 0110` | `96` | 150 |

所以一个 32 位机器码 `0xE3A00000` 写起来只有 8 个字符，还能按位看——中间的 `0` 就是字节里的空位，比一长串 0/1 好检查得多。

C 里写十六进制要加前缀 `0x`：

- `0x10` = 十进制 16
- `0xFF` = 255（一个字节能装的最大值）
- `0x02000000` = NDS 主内存附近的一个典型地址

## 字节 / 半字 / 字

| 名称 | 位数 | 常见用途 |
|------|------|----------|
| 字节 (byte) | 8 | 最小读写单位，可表示 0~255 |
| 半字 (halfword) | 16 | Thumb 指令、部分像素 |
| 字 (word) | 32 | ARM 指令、寄存器宽度 |

一个 32 位字占 4 个字节。问题是：这 4 个字节按什么顺序存进内存？

## 字节序：大端 vs 小端

把 `0x12345678` 按字节拆开，从高到低是：

- `12`（最高字节）
- `34`
- `56`
- `78`（最低字节）

**大端（big-endian）**：最高字节先存低地址，就像我们平时从左往右写数字：

```
地址+0: 12
地址+1: 34
地址+2: 56
地址+3: 78
```

**小端（little-endian）**：最低字节先存低地址：

```
地址+0: 78
地址+1: 56
地址+2: 34
地址+3: 12
```

NDS 的 ARM CPU 是小端。**我们模拟器的 `bus_read32` / `bus_write32` 必须按小端规则拼拆**，否则读出来的字和真机对不上。

## 对我们的 `bus_read` / `bus_write` 意味着什么

内存就是一块 `uint8_t[]` 数组。小端规则下：

`read32(addr)` 把 4 个字节拼成一个 32 位数，**低地址的字节是低位**：

```c
uint32_t val = b0                          // mem[addr+0]，最低字节
             | ((uint32_t)b1 << 8)         // mem[addr+1]
             | ((uint32_t)b2 << 16)        // mem[addr+2]
             | ((uint32_t)b3 << 24);       // mem[addr+3]，最高字节
```

`write32(addr, val)` 反过来，把高位依次拆到高地址：

```c
mem[addr + 0] = (uint8_t)(val & 0xFF);          // 最低字节
mem[addr + 1] = (uint8_t)((val >> 8) & 0xFF);
mem[addr + 2] = (uint8_t)((val >> 16) & 0xFF);
mem[addr + 3] = (uint8_t)((val >> 24) & 0xFF);  // 最高字节
```

`read16` / `write16` 同理，只是只拼 / 拆 2 个字节：低位放低地址，高位放高地址。

## 验证小端

向地址写 `0x12345678` 后逐字节打印，小端应该看到：

```
78 56 34 12
```

这也会成为阶段 2 的验收测试：`write16` 写 `0xABCD`，再检查两个字节是不是 `CD AB`。

## 自测（先别看答案）

1. `0x12345678` 在小端内存里，低地址到高地址依次是 ___。
2. `read32` 为什么用 `b0 | b1<<8 | b2<<16 | b3<<24` 拼接，而不是反过来？
3. 一个 `0xA5` 存进内存占几个字节？

<details>
<summary>答案</summary>

1. `78 56 34 12`。
2. 因为小端是最低字节先存到低地址，`b0`（`mem[addr+0]`）就是整个字的最低 8 位，所以要放到 `<<0` 的位置；`b3` 才是最高 8 位，放到 `<<24`。
3. 1 个字节。`0xA5` 是 8 位，刚好一个字节。

</details>
