# DMA：硬件搬内存（零基础）

## 一句话

**DMA（Direct Memory Access，直接内存访问）= 一个专门「搬数据」的硬件小工人。
你告诉它「从哪搬、搬到哪、搬多少」，它就自己一趟一趟搬完，期间 CPU 不用管。
搬完它会自己停下来（清掉启动位）。**

CPU 拷贝要一条条指令执行：读内存 → 写内存 → 判断搬完没 → 回到开头。N 字节要跑
好几条指令。DMA 是纯硬件：写几个寄存器告诉它任务，它一口气搬完，CPU 可以继续干别的。

NDS 每颗 CPU 有 4 个 DMA 通道（本模拟器阶段 7 只实现 **DMA0** 一条）。

## 一个任务需要三个信息

任何搬数据都需要「从哪、到哪、多少」：

| 寄存器（DMA0） | 地址 | 含义 |
|----------------|------|------|
| `DMA0SAD` | `0x040000B0` | 源地址（Source ADdress） |
| `DMA0DAD` | `0x040000B4` | 目的地址（Destination ADdress） |
| `DMA0CNT_L` | `0x040000B8` | 搬运数量（字数，0 按 0x4000） |
| `DMA0CNT_H` | `0x040000BA` | 控制字（搬多大块、地址怎么走、启动） |

## 控制字 DMA0CNT_H 关键位

```
bit31  使能（写 1 = 启动搬运；搬完硬件自动清 0）
bit26  块大小：0 = 半字（16 位）   1 = 字（32 位）
bit24  源地址固定（不递增）——填色用它
bit22  目的地址固定（不递增）
bit27-29  触发模式：0 = 立即（马上搬），1/2 = VBlank/HBlank 时搬（阶段 7 不实现）
```

### 地址怎么走

默认源和目的地址都**逐个递增**（搬完一块，地址 + 块大小），把一整段数据照搬过去。
如果置了「固定」，地址停在原地不动——源固定 + 目的递增 = 用同一个值刷满一整片内存，
这就是**填色**：把一种颜色写到 VRAM 的很多像素。

## 什么时候搬、什么时候停

- **立即模式**（模式位=0）：软件往 CNT_H 写使能位的那一刻，DMA 立刻把活干完。
- 搬完：硬件把使能位清 0。程序下次再写使能位才会再搬一次。
- 本模拟器简化：写使能位后**同步一次性搬完**（真机上要占几百个周期的总线，这里略）。

## DMA vs CPU 拷贝

| 方式 | 谁干活 | 速度 | 用法 |
|------|--------|------|------|
| CPU 拷贝 | CPU 逐条指令 | 慢 | 灵活，可边搬边算 |
| DMA | 专用硬件 | 快 | 大批量、规律性搬数据（清屏、填色、传缓冲区） |

## 本模拟器如何接入

DMA 寄存器在 IO 区，`io` 模块按地址路由到 `dma` 功能文件。触发搬运用
`bus_read/write` 走完整地址换算——所以源/目的可以是 Main RAM、VRAM，甚至 IO 寄存器。

## 自测

1. 一次 DMA 任务需要哪三个信息？分别写进哪个寄存器？
2. 怎么启动一次立即搬运？搬完会发生什么？
3. 用 DMA 把整屏填成一种颜色，源地址应该怎么设置？

<details>
<summary>答案</summary>

1. 源地址 → `DMA0SAD`（0x040000B0）；目的地址 → `DMA0DAD`（0x040000B4）；
   数量 → `DMA0CNT_L`（0x040000B8）。
2. 往 `DMA0CNT_H`（0x040000BA）写使能位 bit31=1；搬完硬件自动清 0，再写才再搬。
3. 把颜色值放在某地址，源地址设为它并置「源固定」位（bit24），目的地址设为 VRAM
   起点且递增，数量 = 像素数。
</details>
