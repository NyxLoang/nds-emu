# 阶段 17 — NDS 触摸屏 + SPI 总线

> 目标是「顺畅玩 .nds 游戏」：大量游戏靠**触摸屏**交互（点菜单、划地图、拼图等）。
> NDS 的触摸屏控制器（TSC）挂在**主 SPI 总线**上（与阶段 16 卡带存档用的**辅助 SPI 总线**是两套，
> 寄存器地址不同：主 SPI 用 `SPICNT/SPIDATA`，存档用 `AUXSPICNT/AUXSPIDATA`）。本文先讲清协议，再据此实现。

---

## 1. 硬件与寄存器

### 1.1 主 SPI 总线

NDS7 主控一条 4 线 SPI 总线（时钟 / 数据入 / 数据出 / 片选），上面挂了三个从设备：

| 设备号 | 设备 | 用途 |
|--------|------|------|
| 0 | 电源管理（Power Management） | 电池、背光、电源开关 |
| 1 | 固件（Firmware Flash） | 系统设置、触摸校准数据、用户信息 |
| 2 | **触摸屏控制器（TSC）** | 触摸坐标 / 压力 / 麦克风 |
| 3 | 保留 | — |

### 1.2 寄存器地址

- `0x040001C0` — **SPICNT**（16 位，SPI 控制/状态）
- `0x040001C2` — **SPIDATA**（8 位，SPI 数据/选通）

### 1.3 SPICNT 位定义（GBATEK）

| 位 | 名称 | 含义 |
|----|------|------|
| 0-1 | Baudrate | 0=4MHz(固件) 1=2MHz(触摸) 2=1MHz(电源) 3=512KHz |
| 2 | (DSi) 波特率 MSB | NDS 忽略 |
| 3-6 | — | 未用（恒 0） |
| 7 | Busy | 0=就绪 1=忙（**只读**） |
| 8-9 | Device Select | 0=电源 1=固件 **2=触摸** 3=保留 |
| 10 | Transfer Size | 0=8 位(正常) 1=16 位(有 bug) |
| 11 | Chipselect Hold | 0=传输后撤片选 1=保持片选 |
| 12-13 | — | 未用（恒 0） |
| 14 | Interrupt Request | 0=禁用 1=启用（传输完成中断） |
| 15 | SPI Bus Enable | 0=禁用 1=启用 |

- 访问触摸屏的典型写法：`SPICNT = 0x8000(使能) | 0x0200(设备=触摸) | 0x0800(保持片选)`
  = `0x8A00`（波特率再按需加）。
- 与存档一样：**写 SPIDATA 即启动一次 8 位 SPI 传输**（写出的字节沿 MOSI 送出，同时从 MISO 收一个字节，
  传输完成后可从 SPIDATA 读回）。本模拟器用**瞬时模型**（写即完成、Busy 恒 0）。
- 「保持片选（Hold=1）」时连续多次写/读可保持同一设备会话；清 Hold 后片选自动撤下。

## 2. 触摸屏控制器（TSC）协议

芯片：Texas Instruments **TSC2046**（NDS）/ Asahi Kasei **AK4148AVT**（NDS-Lite）。

### 2.1 控制字节（命令，MSB 先发）

| 位 | 名称 | 含义 |
|----|------|------|
| 0-1 | Power Down Mode | 0=转换间掉电 1=单端模式 2/3=不用 |
| 2 | Reference Select | 0=差分（测坐标用） 1=单端（测温度/麦克风用） |
| 3 | Conversion Mode | 0=12 位 1=8 位 |
| 4-6 | Channel Select | 0-7 通道，见下 |
| 7 | Start Bit | 必须为 1 |

### 2.2 通道（Channel Select，命令 bit6-4）

| 通道 | 含义 | 备注 |
|------|------|------|
| 0 | 温度 0 | 需校准 |
| **1** | **Y 位置** | 约 `0B0h..F20h`，`FFFh`=未按下 |
| 2 | 电池电压 | NDS 接 GND，恒 `000h` |
| 3 | Z1 压力 | 对角线压力测量 |
| 4 | Z2 压力 | 对角线压力测量 |
| **5** | **X 位置** | 约 `100h..ED0h`，`000h`=未按下 |
| 6 | AUX / 麦克风 | 接麦克风 |
| 7 | 温度 1 | 与温度 0 的差值 |

- 常用命令（12 位差分，Power Down=0）：

| 命令 | 值 | 通道 |
|------|-----|------|
| TSC_X | `0xD0` | X 位置 |
| TSC_Y | `0x90` | Y 位置 |
| TSC_Z1 | `0xA0` | Z1 压力 |
| TSC_Z2 | `0xB0` | Z2 压力 |
| TSC_BAT | `0xE0` | 电池（恒 0） |
| TSC_AUX | `0xF0` | 麦克风 |

- 8 位模式把 bit3 置 1（如 X=`0xD8`、Y=`0x98`）。

### 2.3 回复数据（命令字节之后的接收内容）

命令字节传输后，MISO 线上依次输出：

```
1 个哑元位(0)  +  8 位或 12 位转换结果(MSB 先)  +  无限填充(0)
```

由于 SPI 寄存器每次固定传 8 位，12 位模式要读 **2 个字节**拼出结果：

| 12 位模式 | 内容 |
|-----------|------|
| 第 1 字节 | 1 哑元位 + 结果 bit11..5（`(result >> 5) & 0x7F`） |
| 第 2 字节 | 结果 bit4..0 + 3 位填充（`(result & 0x1F) << 3`） |

还原：`result = ((byte1 & 0x7F) << 5) | (byte2 >> 3)`。

| 8 位模式 | 内容 |
|-----------|------|
| 第 1 字节 | 1 哑元位 + 结果 bit7..1（`(result >> 1) & 0x7F`） |
| 第 2 字节 | 结果 bit0 + 7 位填充（`(result & 1) << 7`） |

## 3. 典型读取流程（12 位 X/Y）

```
SPICNT = 0x8A00                ; 使能 + 设备=触摸 + 保持片选
SPIDATA = 0xD0                 ; 命令：读 X（启动传输，收第 1 字节）
b1 = SPIDATA                   ; 第 1 字节（结果高 7 位）
SPIDATA = 0x00                 ; 哑元（收第 2 字节）
b2 = SPIDATA                   ; 第 2 字节（结果低 5 位）
SPICNT = 0x8200                ; 清 Hold（传输后自动撤片选）
x = ((b1 & 0x7F) << 5) | (b2 >> 3)
```

- 未按下时：X 读回 `0x000`、Y 读回 `0xFFF`。
- 触摸坐标是**原始 ADC 值**，要经固件里的校准数据（`touch.x1/x2/y1/y2`）换算成屏幕像素
  （游戏/固件负责换算，模拟器只负责如实回传 ADC 值）。

---

## 4. 模拟器实现要点（本阶段）

- 新模块 `src/io/touch.h/.c`：`touch_t` 持 SPICNT/SPIDATA + TSC 命令状态机 + 触摸位置。
- `io` 模块在 0x040001C0..0x040001C3 区间转发到 touch 模块（与 key/disp 同套路）。
- **瞬时模型**：写 SPIDATA 即完成一次传输，按「命令字节（bit7=1）→ 解码通道/分辨率 → 算出 ADC 结果 →
  按回复字节序号回传」推进；Hold=0 时传输后复位命令状态。
- 触摸位置由外部信号 `touch_set_pos(adc_x, adc_y, down)` 设置；未按下按协议回 `X=000h/Y=FFFh`。
- 通道映射按上表（X=5、Y=1、Z1=3、Z2=4、电池=2、麦克风=6、温度=0/7）。

## 5. 验收标准（阶段 17）

- 单元：`touch_write8/touch_read8` 直接喂命令字节——12 位 X/Y 回传字节正确、8 位模式正确、
  未按下回 `X=000h/Y=FFFh`、Hold 清空后命令状态复位。
- 综合：一段 CPU 程序经 SPICNT/SPIDATA 读出 X/Y 坐标，断言 CPU 寄存器/内存里的坐标与设定一致。
- `ctest` 全绿、`test_nds.exe` 全量 0 失败。
