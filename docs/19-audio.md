# 阶段 18 — NDS 音频（16 通道 + 混音）

> 目标是「顺畅玩 .nds 游戏」：游戏要有**声音**（BGM/音效）。NDS 有 16 路硬件音频通道，
> 由 ARM7 主控，混音后从左右两个扬声器输出立体声。本文先讲清寄存器与通道协议，再据此实现。

---

## 1. 硬件概览

- **16 个音频通道**（channel 0..15），每个通道占 16 字节寄存器，基址 `0x04000400 + 通道×0x10`。
- 每个通道支持 4 种格式：
  - **PCM8**（有符号 8 位）
  - **PCM16**（有符号 16 位，小端）
  - **IMA-ADPCM**（4 位差分压缩，带 32 位头）
  - **PSG/Noise**（通道 8–13 = 方波；通道 14–15 = 白噪声）
- 主控：`SOUNDCNT`（0x04000500，主音量 + 主使能）、`SOUNDBIAS`（0x04000504，直流偏置）。
- 混音器采样率 **32768 Hz**，输出立体声（PWM 调制后 10 位）。

---

## 2. 通道寄存器（channel x，基址 `0x04000400 + x*0x10`）

| 偏移 | 寄存器 | 宽度 | 说明 |
|------|--------|------|------|
| +0 | SOUNDxCNT | 32 位 | 控制：音量/声像/循环/格式/启停 |
| +4 | SOUNDxSAD | 32 位 | 数据源地址（指向内存里的波形数据） |
| +8 | SOUNDxTMR | 16 位 | 采样周期（决定音高/采样率） |
| +0xA | SOUNDxPNT | 16 位 | 循环起始点（单位：字 = 4 字节） |
| +0xC | SOUNDxLEN | 32 位 | 数据长度（单位：字） |

### SOUNDxCNT 位定义

| 位 | 名称 | 含义 |
|----|------|------|
| 0-6 | Volume Mul | 音量 0..127（静音..最大） |
| 7 | — | 未用 |
| 8-9 | Volume Div | 0=正常 1=÷2 2=÷4 3=÷16 |
| 10-14 | — | 未用 |
| 15 | Hold | 单发结束后保持最后一采样输出 |
| 16-22 | Panning | 声像 0..127（0=全左 64=居中 127=全右） |
| 23 | — | 未用 |
| 24-26 | Wave Duty | 方波占空比（仅 PSG）：高电平=(N+1)/8 |
| 27-28 | Repeat Mode | 0=手动 1=无限循环 2=单发 3=禁止 |
| 29-30 | Format | 0=PCM8 1=PCM16 2=IMA-ADPCM 3=PSG/Noise |
| 31 | Start/Status | 0=停止 1=启动/忙（写 1 启动） |

### 采样率与长度

- **采样率** = `33,513,982 Hz / SOUNDxTMR`（TMR=0 视作 65536）。
  例：要 32768 Hz，TMR ≈ 1023。
- **长度**：`LEN` 与 `PNT` 以「字」（4 字节）计：
  - PCM8：N 字 = `4*N` 采样；PCM16：N 字 = `2*N` 采样；ADPCM：N 字 = `8*(N-1)` 采样（首字是头）。
  - 单发模式总长 = PNT + LEN；循环模式：先放 PNT 一次，再无限重复 LEN 段。
  - PSG 模式不用长度。

## 3. 主控寄存器

### SOUNDCNT（0x04000500，16 位）

| 位 | 名称 | 含义 |
|----|------|------|
| 0-6 | Master Volume | 主音量 0..127 |
| 8-9 | Left Output | 0=左混音器 1=Ch1 2=Ch3 3=Ch1+Ch3 |
| 10-11 | Right Output | 0=右混音器 1=Ch1 2=Ch3 3=Ch1+Ch3 |
| 12 | Output Ch1 to Mixer | 0=是 1=否 |
| 13 | Output Ch3 to Mixer | 0=是 1=否 |
| 15 | Master Enable | 0=禁用 1=启用 |

### SOUNDBIAS（0x04000504，16 位）

- bit0-9：直流偏置（通常 `0x200`）。混音后的有符号信号 `-0x200..+0x1FF` 加上偏置变成无符号 `0..0x3FF`。

---

## 4. 混音与输出

1. 每个使能通道按自身采样率生成采样，经**音量**（`mul/128` 再除以 `2^div`）与
   **声像**（`left = v*(127-pan)/127`、`right = v*pan/127`）分到左右声道。
2. 16 路累加到左右混音器 → 乘**主音量** → 加 **Bias** 得 10 位无符号输出（中心 `0x200`）。
3. 输出采样率 32768 Hz；主使能关闭时静音（但 Bias 仍输出）。

### 格式细节

- **PCM8**：每个字节是有符号 8 位（-128..127）。
- **PCM16**：每 2 字节小端有符号 16 位（-32768..32767）。
- **IMA-ADPCM**：首 32 位字是头（bit0-6 初始采样、bit8-11 初始步进索引），
  之后每字 8 个 4 位差分（低半字节在前），用 16 级 IMA 步进表解码为 16 位采样。
- **PSG 方波**（通道 8–13）：按 `Wave Duty` 生成 ±满幅方波，频率 = 采样率/8。
- **PSG 噪声**（通道 14–15）：LFSR 生成白噪声，频率 = 采样率。

---

## 5. 模拟器实现要点（本阶段）

- 新模块 `src/snd/snd.h/.c`：`snd_t` 持 16 通道寄存器 + 通道运行时状态 + 主控寄存器。
- `io` 模块在 `0x04000400..0x04000505` 区间转发到 snd 模块；`snd_render(snd, bus, out_l, out_r, n)`
  按 32768 Hz 合成 n 个立体声采样（核心不依赖 SDL，可被 ctest 直接断言）。
- SDL 音频回调在 `nds-emu` 侧（`main.c` 或 `src/snd/` 的 SDL 封装）拉取 `snd_render` 输出喂给声卡。
- 采样位置用定点/浮点累加，支持循环/单发/手动三种模式；Hold 与延迟启动按近似处理。

---

## 6. 验收标准（阶段 18）

- 单元：16 通道 + 主控寄存器写读回一致；PCM8/PCM16/PSG 混音输出采样值与手算一致（音量/声像/主音量/偏置）；
  ADPCM 解一段已知流与预期采样一致；循环/单发的位置推进正确。
- 综合：CPU 程序配好一个通道并启动，`snd_render` 输出与预期波形一致。
- `ctest` 全绿、`test_nds.exe` 全量 0 失败。
