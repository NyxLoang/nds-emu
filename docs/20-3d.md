# NDS 3D 几何引擎（Geometry Engine）

> 阶段 19 预习短文。目标：理解 NDS 的 3D 硬件怎么把「命令流」变成屏幕上的三角形，
> 以便在模拟器里实现一个能出图的最小 3D 管线（几何命令 → 顶点变换 → 光栅化）。

## 1. 整体结构

NDS 的 3D 由两块硬件组成：

- **几何引擎（Geometry Engine，GE）**：吃「命令流」（矩阵、顶点、多边形属性），
  做矩阵变换、顶点变换、裁剪，输出**屏幕空间顶点**和**多边形列表**。
- **渲染引擎（Rendering Engine，RE）**：把几何引擎输出的多边形光栅化成像素
  （贴图、光照、深度、alpha 混合等），写进一个 3D 帧缓冲。

3D 帧缓冲最终作为 2D 引擎里的一个「3D 图层」，与 BG/OBJ 图层按 `DISPCNT` 优先级混合输出。

## 2. 关键寄存器

| 地址 | 名字 | 说明 |
|------|------|------|
| `0x04000400` | `GXFIFO` | 几何命令 FIFO（写）。镜像到 `0x04000400..0x0400043F`（16 字，供 STRD/STM 用） |
| `0x04000440..0x040005FF` | 命令端口 | 按端口地址间接发命令（写参数即触发） |
| `0x04000060` | `DISP3DCNT` | 3D 显示控制（bit0 贴图使能、bit1 高光、bit3 透明、bit12 显示顺序、bit13 3D 层使能等） |
| `0x04000600` | `GXSTAT` | 几何状态（bit16-24 FIFO 条目数、bit25 半空、bit26 空、bit27 忙） |
| `0x04000604` | `RAM_COUNT` | 多边形列表 / 顶点 RAM 计数（只读） |
| `0x04000320` | `GX_STAT_2` | 性能统计（每帧缓冲行数） |

## 3. GXFIFO 命令条目

FIFO 有 **256 条目**，另加一个 **4 条目 PIPE**（共 260）。每个条目 **40 位** =
**8 位命令码 + 32 位参数**。无参数命令占 1 条目，带 N 参数的命令占 N 条目。

- **GXSTAT**：bit16-24 = FIFO 条目数；bit26 = FIFO 空；bit27 = 忙（FIFO/PIPE 有数据或命令仍在执行）。
- 真机：FIFO 满时写会暂停 CPU；DMA 在 FIFO 小于半空时搬 112 字。**模拟器可用「瞬时执行」简化**。

### 命令送入方式（三种）

1. **非打包（unpacked）**：写 `GXFIFO` 的低 8 位 = 命令码（高 24 位为 0），
   之后每个参数再写一次 `GXFIFO`。
2. **打包（packed）**：一个 32 位里打包最多 4 个命令码（各占 8 位），随后依次写各命令参数。
   例：`0x00151515` = 三个 `0x15`（MTX_IDENTITY，无参数）+ 一个 `0x00`（NOP）。
3. **命令端口**：写 `0x04000440 + (命令码 << 2)`（带参数的命令写参数，无参数的写一次哑元）。

## 4. 主要命令（几何）

| 命令 | 参数 | 作用 |
|------|------|------|
| `0x00` NOP | 0 | 空操作（打包填充） |
| `0x10` MTX_MODE | 1 | 选择当前矩阵模式（0=投影、1=位置+方向、2=位置、3=纹理） |
| `0x11` MTX_PUSH | 0 | 当前矩阵入栈 |
| `0x12` MTX_POP | 1 | 出栈（参数 = 回退偏移量） |
| `0x13` MTX_STORE | 1 | 存当前矩阵到栈槽 |
| `0x14` MTX_RESTORE | 1 | 从栈槽恢复当前矩阵 |
| `0x15` MTX_IDENTITY | 0 | 当前矩阵 = 单位阵 |
| `0x16` MTX_LOAD_4x4 | 16 | 载入 4×4 矩阵（列主序，逐元素） |
| `0x17` MTX_LOAD_4x3 | 12 | 载入 4×3 矩阵 |
| `0x18` MTX_MULT_4x4 | 16 | 当前矩阵 × 4×4 |
| `0x19` MTX_MULT_4x3 | 12 | 当前矩阵 × 4×3 |
| `0x1A` MTX_MULT_3x3 | 9 | 当前矩阵 × 3×3 |
| `0x1B` MTX_SCALE | 3 | 缩放 (sx,sy,sz) |
| `0x1C` MTX_TRANS | 3 | 平移 (tx,ty,tz) |
| `0x20` COLOR | 1 | 顶点颜色（RGB555，bit15=alpha） |
| `0x21` NORMAL | 1 | 顶点法线 |
| `0x22` TEXCOORD | 1 | 顶点纹理坐标 |
| `0x23` VTX_16 | 2 | 提交顶点（16 位位置，参数1=XY、参数2=Z） |
| `0x24` VTX_10 | 1 | 提交顶点（10 位位置，1 参数） |
| `0x25` VTX_XY | 1 | 提交顶点（XY，Z 沿用上一顶点） |
| `0x26` VTX_XZ | 1 | 提交顶点（XZ，Y 沿用） |
| `0x27` VTX_YZ | 1 | 提交顶点（YZ，X 沿用） |
| `0x28` VTX_DIFF | 1 | 提交顶点（相对上一顶点增量） |
| `0x29` POLYGON_ATTR | 1 | 多边形属性（光/α/纹理/面朝向等） |
| `0x2A` TEXIMAGE_PARAM | 1 | 纹理图像参数 |
| `0x2B` PLTT_BASE | 1 | 调色板基址 |
| `0x30..0x34` | 1 | 材质/光照（DIF_AMB/SPE_EMI/LIGHT_VECTOR/LIGHT_COLOR/SHININESS） |
| `0x40` BEGIN_VTXS | 1 | 开始顶点列表（参数 = 图元类型） |
| `0x41` END_VTXS | 0 | 结束顶点列表 |
| `0x50` SWAP_BUFFERS | 1 | 交换几何/渲染缓冲（提交一帧） |
| `0x60` VIEWPORT | 1 | 视口（参数打包 x1,y1,x2,y2） |

**无效命令**（10h..1Ch、20h..2Bh、30h..34h、40h..41h、50h、60h、70h..72h 之外）被硬件忽略、不取参数。

## 5. 矩阵与顶点格式

- **矩阵元素**：32 位定点 **1.19.12**（1 符号 + 19 整数 + 12 小数），范围约 ±524288。
- **顶点位置**：16 位定点 **1.3.12**（1 符号 + 3 整数 + 12 小数），范围 **-8.0 .. +7.999**。
  10 位变体为 **1.3.6**。相对/XY/XZ/YZ 命令用于节省带宽，沿用上一顶点的相应分量。
- **矩阵模式**：当前矩阵是「投影矩阵」还是「位置/方向矩阵」由 `MTX_MODE` 决定。
  顶点变换用 `位置矩阵 × 投影矩阵`（即 clip 矩阵），再透视除 w、经视口映射到屏幕。
- **矩阵栈**：投影栈（1 层）+ 位置/方向栈（31 层）+ 纹理栈（1 层）。

## 6. 图元类型（BEGIN_VTXS 参数）

`BEGIN_VTXS` 参数低 2 位 = 图元类型：

| 值 | 图元 | 顶点组织 |
|----|------|----------|
| 0 | 独立三角形 | 每 3 个顶点一个三角形 |
| 1 | 四边形 | 每 4 个顶点一个四边形 |
| 2 | 三角带（strip） | 每新增 1 顶点 + 前 2 顶点成三角形 |
| 3 | 扇形（fan） | 每新增 1 顶点 + 首顶点 + 前一顶点成三角形 |

## 7. 模拟器实现要点（最小管线）

1. **FIFO 解码**：实现 `GXFIFO` 写（瞬时执行）——支持打包/非打包/端口三种送入方式，
   解码出「命令码 + 参数序列」。
2. **矩阵**：4×4 定点矩阵（1.19.12）乘加；实现 `MTX_MODE/IDENTITY/LOAD/MULT/SCALE/TRANS/PUSH/POP`。
3. **顶点**：累计当前颜色/纹理坐标，`VTX_*` 提交时用 clip 矩阵变换 → 透视除 → 视口映射到屏幕。
4. **多边形列表**：`BEGIN_VTXS/END_VTXS` 之间收集顶点，按图元类型拆成三角形。
5. **光栅化**：软件光栅化三角形（本阶段先做**平色**，贴图/光照后续补），写 3D 帧缓冲。
6. **输出**：3D 帧缓冲作为 2D 引擎的 3D 图层（`DISP3DCNT bit13` 使能时）与 BG/OBJ 混合。

### 本阶段验收

- 能复述 3D 命令流 → 顶点变换 → 光栅化流程。
- 写一段命令流（单位阵 + 三角形 3 顶点 + 平色）能光栅化出一个三角形像素到 3D 帧缓冲。
